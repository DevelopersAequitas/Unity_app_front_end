1. Executive Summary & System Overview
This technical documentation provides the complete specification of all 3 distinct chat channels implemented in the PeersUnity
architecture:
1. Direct (1−to-1) Chat: Private peer-to-peer conversations with mutual block protection, media probe metadata processing, real-time read receipts,
typing state broadcasts, FCM push notifications, and separate soft-deletion for user vs everyone.
2. Circle Group Chat: Public communication channel for all approved members of a circle. Includes cursor-based pagination (before_message_id),
quoted replies, granular read tracking (inspecting who read each message), per-user message hiding via PostgreSQL JSONB arrays, and sender-only
deletion for all.
3. Circle Leadership Group Chat: Confidential communication channel exclusively accessible to the 5 authorized circle leadership roles (Founder,
Director, Chair, Vice Chair, Secretary). Features leadership member roster metrics, unread counters, and threaded discussions.
